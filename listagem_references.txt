"""
References — imagens que o arquiteto escolheu para representar intenção.

============================================================================
REGRA ARQUITETURAL
============================================================================

`references` responde por:

    - armazenar imagens de referência (JPG, PNG, WEBP, GIF)
    - registrar título, descrição e categoria
    - organizar em pastas simples (uma camada, sem subpasta)
    - associar a cliente e/ou projeto (contexto opcional)
    - manter histórico de alterações

`references` NÃO responde por:

    - arquivos genéricos (PDF, DOCX, DWG)  → pertence a `documents`
    - identidade do usuário                → pertence a `accounts`
    - contexto do cliente                  → pertence a `clients`
    - projeto                              → pertence a `projects` (futuro)
    - timeline transversal                 → pertence a `timeline`
    - interpretação/IA                     → pertence a `intelligence`
    - importação externa (Pinterest, etc.) → NÃO existe no P0

============================================================================
PRINCÍPIO
============================================================================

    Imagem → significado → contexto → memória visual

References é a biblioteca visual do escritório.

O arquiteto sobe uma imagem, dá um título, explica por que ela importa,
e associa a um cliente e/ou projeto quando fizer sentido.

References NÃO é Pinterest. NÃO é moodboard editor. NÃO é marketplace.

É a memória visual do escritório.

============================================================================
MODELOS (P0)
============================================================================

    Reference           → uma imagem de referência
    ReferenceFolder     → agrupamento visual simples (1 camada)
    ReferenceHistory    → registro de cada alteração

O P0 tem TRÊS MODELOS. Não criamos antecipadamente:

    ❌ ReferenceTag           (tags são complexidade não pedida)
    ❌ ReferenceVersion       (versionamento não existe no P0;
                                substituição registra no histórico)
    ❌ ReferenceComment       (comentários não existem no P0)
    ❌ ReferenceApproval      (aprovação não existe no P0)
    ❌ ReferenceCollection    (board/moodboard não existe no P0)

Cada um nasce quando existir demanda real.

============================================================================
SOBRE A IMAGEM
============================================================================

A imagem é armazenada via `FileField`. O storage é o padrão do projeto
(`DEFAULT_FILE_STORAGE`). Se o projeto estiver com S3-compatible
(Backblaze B2, Cloudflare R2), usa o storage configurado. Se estiver
com `MEDIA_ROOT` local, usa local.

Aceitamos JPG, JPEG, PNG, WEBP e GIF.

Não bloqueamos por lista de extensões. A responsabilidade pela
validação é do serializer / presenter. O model aceita qualquer arquivo,
mas a semântica do domínio é: "isto é uma imagem".

PDF, DOCX, DWG e outros arquivos NÃO entram aqui. Esses são `Document`.

Isso mantém a fronteira limpa:

    Document  → arquivo do escritório (qualquer tipo)
    Reference → imagem de referência visual (só imagem)

============================================================================
SOBRE `project_id`
============================================================================

`project_id` é UUIDField solto, NÃO é FK, porque o app `projects`
ainda não existe.

    REGRA: este UUID representa `projects.Project.id`.
    Quando `projects` existir, isso vira ForeignKey.

Não transformar em `related_object_id`, `context_id` ou qualquer
nome genérico de pseudo-polimorfismo.

============================================================================
SOBRE PASTA
============================================================================

Uma `ReferenceFolder` é agrupamento VISUAL, não semântico.

A organização semântica continua sendo:
    Reference → Client → Project

Pasta é um atalho para "onde guardei isso", não "a que contexto pertence".

Regras:
    - Pasta pertence a UM workspace.
    - Pasta tem nome único por workspace.
    - Reference tem ZERO ou UMA pasta.
    - Excluir pasta NÃO exclui references — elas voltam a ficar soltas.
    - Sem subpastas no P0. Se um dia forem necessárias, adiciona-se `parent`.

============================================================================
SOBRE `category`
============================================================================

`category` é CharField com choices fixas. Não é FK para uma tabela
de categorias porque:

    - o conjunto é pequeno e estável
    - o usuário não cria categorias no P0
    - filtrar por escolha fixa é mais simples que gerenciar tabela

Se no futuro o usuário precisar criar categorias próprias, migra para FK.

============================================================================
SOBRE EXCLUSÃO
============================================================================

DELETE É DELETE. Sem soft delete. Sem lixeira. Sem restore.

Ao excluir uma Reference:
    - a imagem física é removida
    - o registro em `Reference` é removido
    - um `ReferenceHistory` com action='deleted' é criado ANTES da
      exclusão, com FK para o objeto prestes a ser apagado
    - após a exclusão, o FK de `ReferenceHistory` recebe SET_NULL
      automaticamente pelo Django

O histórico sobrevive. A imagem não.

============================================================================
FRONTEIRA CONGELADA (V1)
============================================================================

    accounts      → identidade e autenticação
    workspaces    → tenancy e membros
    console       → governança e capabilities
    clients       → contexto do cliente
    documents     → arquivos (qualquer tipo)
    references    → imagens de referência (este app)
    briefings     → descoberta/contexto (futuro)
    projects      → operação (futuro)
    timeline      → memória factual (futuro)
    intelligence  → interpretação (futuro)

References apenas armazena imagens e seu significado. Não interpreta.
Não versiona. Não comenta. Não aprova. Não cria boards.
"""

default_app_config = 'apps.references.apps.ReferencesConfig'

class ReferenceFolderSerializer(serializers.ModelSerializer):
    """
    Serializer de leitura de pasta.
    """

    reference_count = serializers.SerializerMethodField()
    references_count = serializers.SerializerMethodField()
    items_count = serializers.SerializerMethodField()

        model = ReferenceFolder
        fields = [
            'id',
            'name',
            'cover_url',
            'reference_count',
            'references_count',
            'items_count',
            'created_by', 'created_by_name',
            'created_at',
            'updated_at',
        ]
        read_only_fields = [
            'id',
            'cover_url',
            'reference_count',
            'references_count',
            'items_count',
            'created_by', 'created_by_name',
            'created_at',
            'updated_at',
        ]

    def _count(self, obj):
        annotated = getattr(obj, 'reference_count_annotated', None)
        if annotated is not None:
            return annotated
        return obj.references.count()

    def get_reference_count(self, obj):
        return self._count(obj)

    def get_references_count(self, obj):
        return self._count(obj)

    def get_items_count(self, obj):
        return self._count(obj)

    def get_cover_url(self, obj):
        if not obj.cover:
            return ''
        try:
            return obj.cover.url
        except Exception:
            return ''

class DriveFilesView(APIView):
    """
    Lista imagens do Drive do usuário.

    Exige capability de upload — listar é o passo anterior a
    importar; quem não pode importar, não precisa listar.
    """
    permission_classes = [IsAuthenticated]

    def get(self, request):
        workspace = _current_workspace(request)
        err = _require_capability(request, workspace, 'references.reference.upload')
        if err is not None:
            return err

        query = request.query_params.get('q', '').strip()

        try:
            files = GDriveService.list_files(request.user, query=query)
        except Exception as exc:
            handled = _handle_domain_error(exc)
            if handled is not None:
                return handled
            logger.exception('Erro ao listar arquivos do Drive')
            return Response(
                {'error': 'Erro ao listar arquivos do Google Drive.'},
                status=500,
            )

        return Response({'files': files})

        serializer.is_valid(raise_exception=True)

        folder_id = serializer.validated_data.get('folder_id')
        if folder_id:
            folder = ReferenceFolder.objects.filter(
                id=folder_id, workspace=workspace
            ).first()
            if folder is None:
                return Response(
                    {'error': 'Pasta não encontrada neste workspace.'},
                    status=400,
                )

        try:
            result = GDriveService.import_files(
                workspace=workspace,
                user=request.user,

                folder=folder,
            )

            if handled is not None:

            )

        return Response({
            'imported': ReferenceDetailSerializer(result['imported'], many=True).data,
            'errors': result['errors'],
        }, status=201)

def _extension_of(reference: Reference) -> str:
    ext = (reference.extension or '').strip().lower()
    if ext:
        return ext
    if reference.image and reference.image.name:
        name = reference.image.name
        if '.' in name:
            return name.rsplit('.', 1)[-1].lower()
    title = (reference.title or '').strip()
    if '.' in title:
        return title.rsplit('.', 1)[-1].lower()
    return ''


def _download_filename(reference: Reference) -> str:
    title = (reference.title or 'referencia').strip() or 'referencia'
    base = title.rsplit('.', 1)[0] if '.' in title else title
    base = base.replace('"', '').replace('\\', '').strip() or 'referencia'
    ext = _extension_of(reference)
    return f"{base}.{ext}" if ext else base

    def _require_capability(self, workspace, capability_code):
        membership = WorkspaceMembership.objects.filter(
            workspace=workspace, user=self.request.user,
        ).select_related('governance').first()

        if membership is None:
            return Response(
                {'error': 'Você não é membro deste Workspace'},
                status=status.HTTP_403_FORBIDDEN,
            )
        if membership.governance.key == 'proprietario':
            return None
        has = ConsoleGovernanceCapability.objects.filter(
            governance=membership.governance,
            capability__code=capability_code,
            capability__is_active=True,
        ).exists()
        if not has:
            return Response(
                {'error': f'Sua governança não permite esta ação ({capability_code}).'},
                status=status.HTTP_403_FORBIDDEN,
            )
        return None

    def get_queryset(self):
        workspace = self._current_workspace()
        if workspace is None:
            return Reference.objects.none()

        qs = (
            Reference.objects
            .filter(workspace=workspace)
            .select_related('client', 'folder', 'created_by', 'updated_by')
            .prefetch_related('categories')
            .order_by('-created_at')
        )

        search = (
            self.request.query_params.get('search')
            or self.request.query_params.get('q')
        )
        if search:
            from django.db.models import Q
            qs = qs.filter(
                Q(title__icontains=search)
                | Q(description__icontains=search)
                | Q(categories__name__icontains=search)
                | Q(client__name__icontains=search)
                | Q(folder__name__icontains=search)
                | Q(source__icontains=search)
                | Q(source_url__icontains=search)
            ).distinct()

        client_id = self.request.query_params.get('client')
        if client_id:
            qs = qs.filter(client_id=client_id)

        project_id = self.request.query_params.get('project')
        if project_id:
            qs = qs.filter(project_id=project_id)

        category_id = self.request.query_params.get('category')
        if category_id:
            qs = qs.filter(categories__id=category_id)

        source = self.request.query_params.get('source')
        if source:
            qs = qs.filter(source=source)

        visibility = self.request.query_params.get('visible_to_client')
        if visibility is not None and visibility != '':
            if visibility.lower() in ('1', 'true', 'yes'):
                qs = qs.filter(visible_to_client=True)
            elif visibility.lower() in ('0', 'false', 'no'):
                qs = qs.filter(visible_to_client=False)

        folder_param = self.request.query_params.get('folder')
        if folder_param == 'none':
            qs = qs.filter(folder__isnull=True)
        elif folder_param:
            qs = qs.filter(folder_id=folder_param)

class WorkspaceStorageView(APIView):
    """
    GET /api/workspace/storage/

    Retorna o uso de armazenamento do workspace ativo.

    Resposta:
        {
            "used": 1073741824,        # bytes usados
            "total": 5368709120,        # bytes totais (quota)
            "percent": 20,              # 0-100 (arredondado)
            "used_human": "1.0 GB",
            "total_human": "5.0 GB"
        }
    """

    permission_classes = [IsAuthenticated]

    def get(self, request):
        workspace_id = request.session.get('current_workspace_id')
        if not workspace_id:
            return Response(
                {'error': 'Nenhum workspace ativo'},
                status=http_status.HTTP_400_BAD_REQUEST,
            )

        workspace = WorkspaceQueries.get_for_user(workspace_id, request.user)
        if workspace is None:
            return Response(
                {'error': 'Workspace não encontrado'},
                status=http_status.HTTP_404_NOT_FOUND,
            )

        # Verifica vínculo
        is_member = WorkspaceMembership.objects.filter(
            workspace=workspace, user=request.user,
        ).exists()
        if not is_member:
            return Response(
                {'error': 'Você não é membro deste Workspace'},
                status=http_status.HTTP_403_FORBIDDEN,
            )

        used = self._compute_used_bytes(workspace)
        total = DEFAULT_STORAGE_QUOTA_BYTES
        percent = round((used / total) * 100) if total else 0
        percent = min(100, max(0, percent))

        return Response({
            'used': used,
            'total': total,
            'percent': percent,
            'used_human': self._humanize(used),
            'total_human': self._humanize(total),
        })

    # ------------------------------------------------------------------
    # HELPERS
    # ------------------------------------------------------------------

    @staticmethod
    def _compute_used_bytes(workspace) -> int:
        """
        Soma o tamanho das imagens das referências via `aggregate`.

        Não usa `iterator()` — isso evita o erro de cursor nomeado
        que acontece com PgBouncer / poolers de Postgres em modo
        transaction. É o mesmo padrão do `DocumentService.storage_usage`.
        """
        total = (
            Reference.objects
            .filter(workspace=workspace)
            .aggregate(total=Sum('size'))
            .get('total') or 0
        )
        return int(total)

    @staticmethod
    def _humanize(num_bytes: int) -> str:
        if not num_bytes:
            return '0 B'
        units = ['B', 'KB', 'MB', 'GB', 'TB']
        size = float(num_bytes)
        i = 0
        while size >= 1024 and i < len(units) - 1:
            size /= 1024.0
            i += 1
        return f'{size:.1f} {units[i]}'

"""
Comando de limpeza de imagens órfãs de referências.

USO
---
    # Dry-run (padrão) — apenas reporta
    python manage.py cleanup_reference_orphans

    # Apagar de verdade
    python manage.py cleanup_reference_orphans --confirm

    # Filtrar report por workspace (a checagem de vivos é sempre
    # contra TODOS os workspaces; o filtro é só cosmético no output)
    python manage.py cleanup_reference_orphans --workspace=<uuid>

OPERAÇÃO
--------
A varredura é O(n) no storage. Não chame em requests. Rode via
cron / Celery beat. Sugestão: uma vez por dia, fora do horário
de pico.

Em caso de falha de rede no storage, o comando retorna código de
saída != 0 e imprime os erros. Configure o cron para capturar
esse código (por exemplo, com `|| echo "FALHA"` ou envio de e-mail).

SEGURANÇA
---------
A função `find_orphan_images` NUNCA retorna arquivos referenciados
por qualquer `Reference.image`, de qualquer workspace. Só devolve
o que não está em nenhum registro. Portanto, apagar o resultado
é seguro por construção.
"""

import sys

from django.core.management.base import BaseCommand, CommandError

from apps.references.services.orphan_cleanup import (
    find_orphan_images,
    delete_orphan_images,
)
from apps.workspaces.models import Workspace


class Command(BaseCommand):
    help = 'Detecta e remove imagens órfãs de referências.'

    def add_arguments(self, parser):
        parser.add_argument(
            '--workspace',
            type=str,
            default=None,
            help='UUID do workspace (apenas para rotular o report).',
        )
        parser.add_argument(
            '--confirm',
            action='store_true',
            help='Sem isso, apenas reporta (dry-run).',
        )
        parser.add_argument(
            '--max-print',
            type=int,
            default=50,
            help='Máximo de nomes a imprimir (default: 50).',
        )

    def handle(self, *args, **opts):
        workspace = None
        if opts['workspace']:
            workspace = Workspace.objects.filter(pk=opts['workspace']).first()
            if workspace is None:
                raise CommandError('Workspace não encontrado.')

        scope = f'workspace={workspace.pk}' if workspace else 'global'

        try:
            orphans = find_orphan_images(workspace=workspace)
        except Exception as exc:
            self.stderr.write(self.style.ERROR(
                f'[{scope}] Falha ao varrer o storage: {exc}'
            ))
            sys.exit(1)

        self.stdout.write(f'[{scope}] Órfãos encontrados: {len(orphans)}')

        max_print = max(0, int(opts['max_print']))
        for name in orphans[:max_print]:
            self.stdout.write(f'  - {name}')
        if len(orphans) > max_print:
            self.stdout.write(f'  ... (+{len(orphans) - max_print})')

        if not opts['confirm']:
            self.stdout.write(self.style.WARNING(
                'Dry-run. Nada foi apagado. Use --confirm para apagar.'
            ))
            return

        if not orphans:
            self.stdout.write(self.style.SUCCESS('Nada a apagar.'))
            return

        report = delete_orphan_images(orphans)
        self.stdout.write(self.style.SUCCESS(
            f"deleted={report['deleted']} failed={report['failed']}"
        ))

        if report['failed'] > 0:
            self.stderr.write(self.style.ERROR(
                f"{report['failed']} arquivo(s) não puderam ser removidos. "
                f"Veja o log para detalhes."
            ))
            sys.exit(1)

"""
Modelo ReferenceHistory.

Registra cada alteração feita em uma Reference.

REGRA ARQUITETURAL
------------------
`ReferenceHistory` é o registro histórico do ciclo de vida da referência.
Ele não armazena a imagem. Ele armazena o que aconteceu com ela.

Ações registradas:

    created               → referência foi criada
    renamed               → título alterado
    edited                → descrição / categoria alterada
    image_replaced        → imagem física substituída
    folder_changed        → movida para outra pasta (ou solta)
    client_associated     → cliente vinculado
    client_removed        → cliente desvinculado
    project_associated    → projeto vinculado
    project_removed       → projeto desvinculado
    visibility_changed    → visibilidade ao cliente alterada
    deleted               → referência excluída

SOBRE `previous_value` E `new_value`
------------------------------------
Campos JSONField genéricos, NULLABLE.

Cada ação preenche o que fizer sentido:

    renamed
        previous_value = {"title": "Cozinha"}
        new_value      = {"title": "Cozinha integrada"}

    client_associated
        previous_value = {"client_id": None}
        new_value      = {"client_id": "<uuid>"}

    folder_changed
        previous_value = {"folder_id": "<uuid>"}
        new_value      = {"folder_id": None}

    visibility_changed
        previous_value = {"visible_to_client": False}
        new_value      = {"visible_to_client": True}

Não criamos campos específicos por ação. previous/new genéricos
resolvem todos os casos sem inflar o schema.

SOBRE `reference` NULLABLE
--------------------------
`reference` é FK nullable com SET_NULL.

Quando uma Reference é excluída:
    - a imagem física é removida
    - o registro em `Reference` é apagado
    - o FK em `ReferenceHistory` recebe NULL

Isso preserva a auditoria (quem excluiu, quando) sem preservar
a imagem.

SOBRE `user`
------------
`user` é FK nullable com SET_NULL.

Se o usuário que fez a ação for excluído do Clivo, o histórico
permanece com `user = NULL`. O `timestamp` e a `action` permanecem.

SOBRE IMUTABILIDADE
-------------------
`ReferenceHistory` é APPEND-ONLY.

Não existe update. Não existe delete. Cada linha é um fato
ocorrido, e fatos não mudam.

Views de histórico só permitem leitura.

        if self.extension:
            return self.extension.upper()

"""
ReferenceFolderService — ciclo de vida da pasta.
"""

import logging

from django.db import IntegrityError, transaction

from apps.references.models import Reference, ReferenceFolder
from apps.references.exceptions import (
    ReferenceFolderNotFoundError,
    ReferenceFolderNameConflictError,
    ReferenceFolderError,
)

logger = logging.getLogger('references')


class ReferenceFolderService:

    # ------------------------------------------------------------------
    # LEITURA
    # ------------------------------------------------------------------

    @staticmethod
    def list_for_workspace(workspace):
        from django.db.models import Count, Q

        return (
            ReferenceFolder.objects
            .filter(workspace=workspace)
            .annotate(
                reference_count_annotated=Count(
                    'references',
                    filter=Q(references__workspace=workspace),
                    distinct=True,
                )
            )
            .order_by('name')
        )

    @staticmethod
    def get_or_raise(folder_id, workspace) -> ReferenceFolder:
        folder = (
            ReferenceFolder.objects
            .filter(id=folder_id, workspace=workspace)
            .first()
        )
        if folder is None:
            raise ReferenceFolderNotFoundError('Pasta não encontrada.')
        return folder

    @staticmethod
    def count_unsorted(workspace) -> int:
        return (
            Reference.objects
            .filter(workspace=workspace, folder__isnull=True)
            .count()
        )

    # ------------------------------------------------------------------
    # CRIAÇÃO
    # ------------------------------------------------------------------

    @staticmethod
    @transaction.atomic
    def create(*, workspace, name: str, actor=None) -> ReferenceFolder:
        name = (name or '').strip()

        if not name:
            raise ReferenceFolderError('O nome da pasta não pode ser vazio.')

        if len(name) > 100:
            raise ReferenceFolderError(
                'O nome da pasta pode ter no máximo 100 caracteres.'
            )

        exists = ReferenceFolder.objects.filter(
            workspace=workspace, name__iexact=name
        ).exists()

        if exists:
            raise ReferenceFolderNameConflictError(
                f'Já existe uma pasta chamada "{name}" neste workspace.'
            )

        try:
            folder = ReferenceFolder.objects.create(
                workspace=workspace,
                name=name,
                created_by=actor,
            )
        except IntegrityError as exc:
            raise ReferenceFolderNameConflictError(
                f'Já existe uma pasta chamada "{name}" neste workspace.'
            ) from exc

        logger.info(
            'Pasta criada: workspace=%s folder=%s name=%s',
            workspace.pk, folder.pk, folder.name,
        )
        return folder

    # ------------------------------------------------------------------
    # RENOMEAR
    # ------------------------------------------------------------------

    @staticmethod
    @transaction.atomic
    def rename(*, folder: ReferenceFolder, new_name: str, actor=None) -> ReferenceFolder:
        new_name = (new_name or '').strip()

        if not new_name:
            raise ReferenceFolderError('O nome da pasta não pode ser vazio.')

        if len(new_name) > 100:
            raise ReferenceFolderError(
                'O nome da pasta pode ter no máximo 100 caracteres.'
            )

        if new_name == folder.name:
            return folder

        conflict = (
            ReferenceFolder.objects
            .filter(workspace=folder.workspace, name__iexact=new_name)
            .exclude(id=folder.pk)
            .exists()
        )

        if conflict:
            raise ReferenceFolderNameConflictError(
                f'Já existe uma pasta chamada "{new_name}" neste workspace.'
            )

        folder.name = new_name
        folder.save(update_fields=['name', 'updated_at'])

        return folder

    # ------------------------------------------------------------------
    # CAPA
    # ------------------------------------------------------------------

    @staticmethod
    @transaction.atomic
    def set_cover(*, folder: ReferenceFolder, uploaded_file) -> ReferenceFolder:
        """
        Define a capa da pasta. Substitui a anterior, se existir.
        Aceita qualquer imagem — validação básica de extensão.
        """
        if uploaded_file is None:
            raise ReferenceFolderError('Nenhuma imagem foi enviada.')

        name = getattr(uploaded_file, 'name', '') or ''
        ext = name.rsplit('.', 1)[-1].lower() if '.' in name else ''
        if ext not in {'jpg', 'jpeg', 'jfif', 'png', 'webp', 'gif'}:
            raise ReferenceFolderError(
                'Formato inválido. Envie JPG, PNG, WEBP ou GIF.'
            )

        # Remove a capa antiga do storage (best-effort)
        old_cover_name = None
        old_cover_storage = None
        if folder.cover:
            try:
                old_cover_name = folder.cover.name
                old_cover_storage = folder.cover.storage
            except Exception:
                pass

        try:
            folder.cover.save(name, uploaded_file, save=False)
        except Exception as exc:
            logger.exception('Falha ao salvar capa no storage')
            raise ReferenceFolderError('Falha ao salvar a capa no storage.') from exc

        folder.save(update_fields=['cover', 'updated_at'])

        if old_cover_name and old_cover_storage:
            try:
                old_cover_storage.delete(old_cover_name)
            except Exception:
                logger.warning(
                    'Não foi possível remover a capa antiga: %s',
                    old_cover_name,
                )

        return folder

    @staticmethod
    @transaction.atomic
    def clear_cover(*, folder: ReferenceFolder) -> ReferenceFolder:
        if not folder.cover:
            return folder

        old_cover_name = folder.cover.name
        old_cover_storage = folder.cover.storage

        folder.cover = None
        folder.save(update_fields=['cover', 'updated_at'])

        try:
            old_cover_storage.delete(old_cover_name)
        except Exception:
            logger.warning('Não foi possível remover a capa: %s', old_cover_name)

        return folder

    # ------------------------------------------------------------------
    # EXCLUSÃO
    # ------------------------------------------------------------------

    @staticmethod
    @transaction.atomic
    def delete(folder: ReferenceFolder) -> None:
        folder_id = folder.pk
        folder_name = folder.name
        workspace_id = folder.workspace_id

        # Remove a capa do storage (best-effort)
        if folder.cover:
            try:
                folder.cover.delete(save=False)
            except Exception:
                logger.warning('Não foi possível remover a capa ao excluir pasta')

        folder.delete()

        logger.info(
            'Pasta excluída: workspace=%s folder=%s name=%s',
            workspace_id, folder_id, folder_name,
        )

"""
GDriveService — importação de imagens do Google Drive.

============================================================================
FILOSOFIA
============================================================================

O Google Drive é uma FONTE, não uma biblioteca paralela.

Fluxo:
    Google Drive → Selecionar → Importar → Reference (Clivo)

Uma vez importada, a imagem é propriedade do Clivo. Não sincroniza.
A `source='gdrive'` e `source_url` guardam apenas o histórico de onde
veio, para o usuário saber a origem.

============================================================================
AUTENTICAÇÃO
============================================================================

Usamos o `SocialToken` do AllAuth (provider='google').
Para isso funcionar, `SOCIALACCOUNT_STORE_TOKENS` precisa ser `True`
no settings. Sem isso, o AllAuth autentica mas não guarda o token
e a Drive API não pode ser chamada.

Para o refresh funcionar (access token expira em 1h), é OBRIGATÓRIO
que o settings tenha:

    'AUTH_PARAMS': {
        'access_type': 'offline',
        'prompt': 'consent',
    },

Sem isso, o Google só devolve access_token e o `token_secret` (refresh)
fica vazio. Quando o access expira, a renovação falha.

============================================================================
CAPABILITIES
============================================================================

Esta camada NÃO checa capabilities — quem decide se o usuário pode
listar/importar é a view (`DriveFilesView`, `DriveImportView`), via
`_require_capability(workspace, 'references.reference.upload')`.
"""

import io
import logging
from typing import List, Dict, Optional

from django.core.files.base import ContentFile

from apps.references.models import Reference
from apps.references.services.reference_service import ReferenceService
from apps.references.exceptions import ReferenceInvalidImageError

logger = logging.getLogger('references')


DRIVE_SCOPES = [
    'https://www.googleapis.com/auth/drive.readonly',
    'https://www.googleapis.com/auth/drive.file',
]


MSG_NO_SOCIAL = (
    'Sua conta não está conectada ao Google. '
    'Faça login com Google novamente.'
)
MSG_NO_TOKEN = (

    'Faça login com Google novamente para autorizar.'
)
MSG_NO_REFRESH = (

    'Por favor, reconecte sua conta Google para permitir '
    'que o Clivo acesse seu Drive.'
)
MSG_NO_LIBS = (

    'Contate o suporte.'
)
MSG_BUILD_FAIL = (
    'Falha ao conectar ao Google Drive. Tente novamente.'
)
MSG_LIST_FAIL = (
    'Falha ao listar arquivos do Google Drive. '
    'Verifique se a permissão de leitura foi concedida.'
)
MSG_DOWNLOAD_FAIL = (
    'Falha ao baixar o arquivo do Google Drive.'
)


class GDriveService:

    # ------------------------------------------------------------------
    # DIAGNÓSTICO
    # ------------------------------------------------------------------

    @staticmethod
    def is_connected(user) -> bool:
        """
        Retorna True só se o usuário tem SocialAccount Google E refresh
        token válido E credenciais configuradas. Mesma régua usada por
        `_get_service`.
        """
        try:
            return GDriveService._get_credentials(user) is not None
        except Exception:
            return False

    @staticmethod
    def connection_status(user) -> Dict:
        """
        Diagnóstico completo para o frontend decidir o que mostrar.
        Retorna um dict com flags independentes.
        """
        result = {
            'connected': False,
            'has_social': False,
            'has_token': False,
            'has_refresh': False,
            'needs_reconnect': False,
            'user_email': None,
        }

        try:
            from allauth.socialaccount.models import SocialAccount, SocialToken
        except ImportError:
            return result

        social = SocialAccount.objects.filter(
            user=user, provider='google'
        ).first()
        if not social:
            return result

        result['has_social'] = True
        result['user_email'] = social.user.email

        token = SocialToken.objects.filter(account=social).first()
        if not token or not token.token:
            return result

        result['has_token'] = True
        result['has_refresh'] = bool(token.token_secret)

        if result['has_refresh']:
            result['connected'] = True
        else:
            result['needs_reconnect'] = True

        return result

    # ------------------------------------------------------------------
    # AUTENTICAÇÃO
    # ------------------------------------------------------------------

    @staticmethod
    def _get_credentials(user):
        try:
            from allauth.socialaccount.models import SocialAccount, SocialToken
        except ImportError:
            logger.warning('allauth não disponível — GDrive desabilitado')
            return None

        social = SocialAccount.objects.filter(
            user=user, provider='google'
        ).first()
        if not social:
            logger.info('GDrive: usuário %s sem SocialAccount Google.', user.pk)
            return None

        token = SocialToken.objects.filter(account=social).first()
        if not token or not token.token:
            logger.info(
                'GDrive: SocialToken ausente para user=%s. '
                'SOCIALACCOUNT_STORE_TOKENS está True?',
                user.pk,
            )
            return None

        refresh_token = token.token_secret or None
        if not refresh_token:
            logger.warning(
                'GDrive: usuário %s tem access token mas SEM refresh_token. '
                'Reconecte a conta Google com access_type=offline + prompt=consent.',
                user.pk,
            )
            return None

        try:
            from google.oauth2.credentials import Credentials
        except ImportError:
            logger.warning('google-auth não instalado')
            return None

        try:
            from django.conf import settings
            client_id = getattr(settings, 'GOOGLE_CLIENT_ID', '') or ''
            client_secret = getattr(settings, 'GOOGLE_CLIENT_SECRET', '') or ''
        except Exception:
            client_id = ''
            client_secret = ''

        if not client_id or not client_secret:
            logger.warning(
                'GDrive: GOOGLE_CLIENT_ID ou GOOGLE_CLIENT_SECRET ausente.'
            )
            return None

        creds = Credentials(
            token=token.token,
            refresh_token=refresh_token,
            token_uri='https://oauth2.googleapis.com/token',
            client_id=client_id,
            client_secret=client_secret,
            scopes=DRIVE_SCOPES,
        )
        return creds

    @staticmethod
    def _get_service(user):
        try:
            from allauth.socialaccount.models import SocialAccount, SocialToken
        except ImportError:
            raise ReferenceInvalidImageError(
                'Integração com Google indisponível no servidor.'
            )

        social = SocialAccount.objects.filter(
            user=user, provider='google'
        ).first()
        if not social:
            raise ReferenceInvalidImageError(MSG_NO_SOCIAL)

        token = SocialToken.objects.filter(account=social).first()
        if not token or not token.token:
            raise ReferenceInvalidImageError(MSG_NO_TOKEN)

        if not token.token_secret:
            raise ReferenceInvalidImageError(MSG_NO_REFRESH)

        try:
            from google.oauth2.credentials import Credentials
            from googleapiclient.discovery import build
        except ImportError:
            logger.exception('google-auth/google-api-python-client não instalados')
            raise ReferenceInvalidImageError(MSG_NO_LIBS)

        creds = GDriveService._get_credentials(user)
        if creds is None:
            raise ReferenceInvalidImageError(MSG_NO_REFRESH)

        try:
            return build('drive', 'v3', credentials=creds, cache_discovery=False)
        except Exception as exc:
            logger.exception('Falha ao construir cliente do Drive: %s', exc)
            raise ReferenceInvalidImageError(MSG_BUILD_FAIL)

    # ------------------------------------------------------------------
    # LISTAGEM
    # ------------------------------------------------------------------

    @staticmethod
    def list_files(user, query: str = '', page_size: int = 50) -> List[Dict]:
        """
        Lista imagens do Drive do usuário.

        Só imagens — o Drive serve como fonte visual para references.
        Arquivos nativos do Google (Docs, Sheets, ...) são ignorados.
        """
        service = GDriveService._get_service(user)

        q_parts = ["trashed = false"]
        q_parts.append("mimeType contains 'image/'")
        if query:
            safe_query = query.replace("'", "\\'")
            q_parts.append(f"name contains '{safe_query}'")
        q = " and ".join(q_parts)

        try:
            response = service.files().list(
                q=q,
                pageSize=page_size,
                fields='files(id,name,mimeType,size,iconLink,webViewLink,modifiedTime)',
                orderBy='modifiedTime desc',
            ).execute()
        except Exception as exc:
            logger.exception('Falha ao listar arquivos do Drive: %s', exc)
            raise ReferenceInvalidImageError(MSG_LIST_FAIL)

        files = response.get('files', []) or []

        native_mimes = {
            'application/vnd.google-apps.document',

        web_view_link = file_meta.get('webViewLink') or ''

        try:
            from googleapiclient.http import MediaIoBaseDownload
            request = service.files().get_media(fileId=file_id)
            fh = io.BytesIO()
            downloader = MediaIoBaseDownload(fh, request)
            done = False
            while not done:

                f'Falha ao baixar "{file_name}" do Google Drive.'
            )

        content = ContentFile(fh.read())
        content.name = file_name
        try:
            content.size = len(content.file.getvalue())
        except Exception:
            pass

        return ReferenceService.upload(
            workspace=workspace,
            uploaded_file=content,
            title=title,
            description='',
            category='',
            folder=folder,
            created_by=user,
            source=Reference.SOURCE_GDRIVE,
            source_url=web_view_link,
            visible_to_client=False,
        )

        *,
        workspace,
        user,
        files_meta: List[Dict],
        folder=None,

        errors = []

                    workspace=workspace,
                    user=user,

                    folder=folder,

                errors.append({
                    'name': meta.get('name') or 'imagem',
                    'error': str(exc),
                })

"""
Validação real de imagem para o módulo references.

Diferente da validação superficial (extensão + tamanho > 0), aqui
inspecionamos o CONTEÚDO do arquivo:

    - magic bytes (assinatura binária) para confirmar que é imagem
    - Pillow para confirmar que abre, é válida e tem dimensões
    - limite de tamanho configurável
    - limite de pixels (largura x altura) configurável

SOBRE PILLOW
------------
Pillow é OBRIGATÓRIO em produção. Sem Pillow, a validação cai para
apenas magic bytes — o que bloqueia arquivos maliciosos com extensão
falsa, mas NÃO valida dimensões nem detecta imagens corrompidas com
cabeçalho válido.

Para forçar a obrigatoriedade, defina em settings:

    REFERENCES_REQUIRE_PILLOW = True   # padrão em produção

Se `REFERENCES_REQUIRE_PILLOW` for True e Pillow não estiver
instalado, `validate_image_content` levanta erro claro. Isso evita
subir um deploy onde a validação é silenciosamente mais fraca.

Em testes/CI, você pode deixar `REFERENCES_REQUIRE_PILLOW = False`
para não exigir a lib. Em produção, sempre True.

Este módulo é importado tanto pelo ReferenceService.upload quanto
pelo replace_image, garantindo a mesma régua em todos os caminhos
de entrada.
"""

import logging
from typing import Optional

from django.conf import settings

logger = logging.getLogger('references')


# =========================================================================
# LIMITES (configuráveis via settings)
# =========================================================================

# Tamanho máximo por imagem. Default: 25 MB.
DEFAULT_MAX_IMAGE_SIZE_BYTES = 25 * 1024 * 1024

# Dimensão máxima em pixels (largura * altura). Default: 100 MP.
# Serve para evitar bombas de descompressão (imagem pequena no disco
# que explode em memória ao abrir).
DEFAULT_MAX_IMAGE_PIXELS = 100_000_000

# Pillow obrigatório? Default True — o comportamento seguro.
# Em CI sem Pillow, defina settings.REFERENCES_REQUIRE_PILLOW = False.
DEFAULT_REQUIRE_PILLOW = True


# =========================================================================
# MAGIC BYTES
# =========================================================================
# Assinaturas binárias mínimas. Não substituem Pillow — apenas garantem
# que o arquivo COMEÇA como uma imagem.
#
# Fonte: file signature table (Gary Kessler) — subconjunto relevante.

MAGIC_SIGNATURES = [
    (b'\xff\xd8\xff', 'jpeg'),
    (b'\x89PNG\r\n\x1a\n', 'png'),
    (b'GIF87a', 'gif'),
    (b'GIF89a', 'gif'),
    (b'RIFF', 'webp_maybe'),
    (b'BM', 'bmp'),
    (b'II*\x00', 'tiff'),
    (b'MM\x00*', 'tiff'),
]


class ImageValidationError(Exception):
    """Levantada quando a imagem não passa na validação."""
    pass


# =========================================================================
# API PÚBLICA
# =========================================================================

def validate_image_content(uploaded_file) -> str:
    """
    Valida o conteúdo de uma imagem enviada.

    Retorna o "kind" detectado (ex: "jpeg", "png", "gif", "webp").
    Levanta ImageValidationError se o arquivo não for uma imagem válida.

    Não altera o ponteiro de leitura do arquivo no final — garante
    que ele fica no início para o storage conseguir salvar.
    """
    if uploaded_file is None:
        raise ImageValidationError('Nenhuma imagem foi enviada.')

    name = getattr(uploaded_file, 'name', None)
    if not name:
        raise ImageValidationError('A imagem enviada não possui nome.')

    size = getattr(uploaded_file, 'size', None)
    if size is None or size <= 0:
        raise ImageValidationError('A imagem enviada está vazia.')

    max_size = int(
        getattr(settings, 'REFERENCES_MAX_IMAGE_SIZE_BYTES',
                DEFAULT_MAX_IMAGE_SIZE_BYTES)
    )
    if max_size > 0 and size > max_size:
        raise ImageValidationError(
            f'A imagem excede o tamanho máximo permitido '
            f'({_humanize(max_size)}).'
        )

    # Lê os primeiros bytes para checar a assinatura
    try:
        uploaded_file.seek(0)
        header = uploaded_file.read(32)
    except Exception as exc:
        raise ImageValidationError(
            'Não foi possível ler o conteúdo da imagem.'
        ) from exc
    finally:
        try:
            uploaded_file.seek(0)
        except Exception:
            pass

    if not header or len(header) < 4:
        raise ImageValidationError('Arquivo muito pequeno para ser imagem.')

    kind = _detect_magic(header)
    if kind is None:
        raise ImageValidationError(
            'O arquivo enviado não é uma imagem válida.'
        )

    if kind == 'webp_maybe':
        if len(header) >= 12 and header[8:12] == b'WEBP':
            kind = 'webp'
        else:
            raise ImageValidationError(
                'O arquivo enviado não é uma imagem válida.'
            )

    declared_ext = _extension_of(name)
    if declared_ext and not _extension_matches(declared_ext, kind):
        logger.info(
            'Extensão declarada "%s" não bate com tipo detectado "%s" '
            'para arquivo "%s". Aceitando mesmo assim.',
            declared_ext, kind, name,
        )

    # -------------------------------------------------------------------
    # Validação profunda com Pillow.
    #
    # Se REQUIRE_PILLOW for True e a lib não estiver instalada, FALHA
    # com mensagem clara. Isso evita produção com validação degradada.
    # -------------------------------------------------------------------
    require_pillow = bool(
        getattr(settings, 'REFERENCES_REQUIRE_PILLOW',
                DEFAULT_REQUIRE_PILLOW)
    )
    pillow_available = _pillow_available()

    if require_pillow and not pillow_available:
        logger.error(
            'REFERENCES_REQUIRE_PILLOW=True mas Pillow não está '
            'instalado. A validação profunda de imagens está '
            'desabilitada. Instale Pillow: pip install Pillow'
        )
        raise ImageValidationError(
            'Validação de imagem indisponível no servidor. '
            'Contate o suporte.'
        )

    if pillow_available:
        pillow_error = _validate_with_pillow(uploaded_file)
        if pillow_error is not None:
            raise ImageValidationError(pillow_error)

    try:
        uploaded_file.seek(0)
    except Exception:
        pass

    return kind


def pillow_is_available() -> bool:
    """Diagnóstico público — útil para health checks."""
    return _pillow_available()


# =========================================================================
# HELPERS INTERNOS
# =========================================================================

def _pillow_available() -> bool:
    try:
        import PIL.Image  # noqa: F401
        return True
    except ImportError:
        return False


def _detect_magic(header: bytes) -> Optional[str]:
    for sig, kind in MAGIC_SIGNATURES:
        if header.startswith(sig):
            return kind
    return None


def _extension_of(filename: str) -> str:
    if not filename or '.' not in filename:
        return ''
    return filename.rsplit('.', 1)[-1].lower()


def _extension_matches(ext: str, kind: str) -> bool:
    if ext in ('jpg', 'jpeg', 'jfif') and kind == 'jpeg':
        return True
    if ext == 'png' and kind == 'png':
        return True
    if ext == 'gif' and kind == 'gif':
        return True
    if ext == 'webp' and kind == 'webp':
        return True
    if ext == 'bmp' and kind == 'bmp':
        return True
    if ext in ('tif', 'tiff') and kind == 'tiff':
        return True
    return False


def _validate_with_pillow(uploaded_file) -> Optional[str]:
    """
    Tenta abrir com Pillow. Retorna mensagem de erro (str) ou None.
    Pressupõe que Pillow está instalado (chamador verifica antes).
    """
    from PIL import Image

    max_pixels = int(
        getattr(settings, 'REFERENCES_MAX_IMAGE_PIXELS',
                DEFAULT_MAX_IMAGE_PIXELS)
    )

    try:
        uploaded_file.seek(0)
        img = Image.open(uploaded_file)
        img.verify()
    except Exception as exc:
        logger.warning('Pillow recusou a imagem: %s', exc)
        return 'A imagem enviada parece estar corrompida ou inválida.'

    try:
        uploaded_file.seek(0)
        img = Image.open(uploaded_file)
        width, height = img.size
        if width <= 0 or height <= 0:
            return 'A imagem tem dimensões inválidas.'
        if max_pixels > 0 and (width * height) > max_pixels:
            return (
                f'A imagem tem dimensões muito grandes '
                f'({width}x{height}). O limite é '
                f'{_humanize_int(max_pixels)} pixels totais.'
            )
    except Exception as exc:
        logger.warning('Pillow falhou ao checar dimensões: %s', exc)
        return 'Não foi possível ler as dimensões da imagem.'
    finally:
        try:
            uploaded_file.seek(0)
        except Exception:
            pass

    return None


def _humanize(num_bytes: int) -> str:
    if not num_bytes:
        return '0 B'
    units = ['B', 'KB', 'MB', 'GB']
    size = float(num_bytes)
    i = 0
    while size >= 1024 and i < len(units) - 1:
        size /= 1024.0
        i += 1
    return f'{size:.1f} {units[i]}'


def _humanize_int(n: int) -> str:
    """Formata inteiro com separador de milhar em pt-BR (ponto)."""
    return f'{n:,}'.replace(',', '.')

"""
Rotina de detecção e limpeza de imagens órfãs no storage.

============================================================================
CONTEXTO
============================================================================

`replace_image` e `delete` são "best-effort" em relação ao storage:

    - Se a remoção da imagem antiga falha, sobra arquivo órfão.
    - Se a atualização do banco falha após salvar no storage, sobra
      arquivo órfão.
    - Se o processo morre entre as duas etapas, sobra arquivo órfão.

Este módulo fornece duas operações:

    find_orphan_images(workspace=None) → list[str] (nomes no storage)
    delete_orphan_images(names)        → dict (relatório)

IMPORTANTE
----------
- `find_orphan_images` NÃO apaga nada. Só compara o storage com o
  banco. Rode em um management command (cron / manual).
- `delete_orphan_images` apaga os nomes passados. Chamado por quem
  já decidiu que aquilo é lixo.
- A varredura do storage é feita sob o prefixo `references/`. Por
  padrão, TODOS os workspaces compartilham esse prefixo — então a
  checagem de "vivo" é feita contra **todos** os workspaces, não
  só o passado como filtro. O parâmetro `workspace` restringe
  apenas o relatório, não a fonte de verdade.

  Ou seja: a limpeza de A NUNCA apaga arquivo referenciado por B.

- Não mexe em arquivos de outros módulos (documents, etc.).
"""

import logging
from typing import Iterable, List

from apps.references.models import Reference

logger = logging.getLogger('references')


# =========================================================================
# DETECÇÃO
# =========================================================================

def find_orphan_images(workspace=None) -> List[str]:
    """
    Retorna a lista de nomes de arquivo que existem no storage sob
    `references/` mas NÃO estão referenciados por NENHUMA
    `Reference.image` de NENHUM workspace.

    O parâmetro `workspace`, quando passado, filtra **apenas o
    retorno do log** — a checagem de "vivo" é sempre feita contra
    todos os workspaces, para garantir que nenhum arquivo válido de
    outro workspace seja apagado.

    ATENÇÃO: é operação O(n) no storage. Rode com moderação.
    """
    from django.core.files.storage import default_storage

    # Nomes vivos: TODOS os workspaces, sempre. Sem filtro.
    # Se filtrássemos por workspace, apagaríamos arquivos legítimos
    # de outros workspaces que compartilham o prefixo `references/`.
    live = set(
        Reference.objects
        .exclude(image='')
        .values_list('image', flat=True)
    )

    # Lista arquivos do storage sob "references/"
    try:
        _dirs, files = default_storage.listdir('references/')
    except FileNotFoundError:
        # Pasta ainda não existe — nada a varrer.
        return []

    orphans: List[str] = []
    for fname in files:
        full_name = f'references/{fname}'
        if full_name not in live:
            orphans.append(full_name)

    return orphans


# =========================================================================
# LIMPEZA
# =========================================================================

def delete_orphan_images(names: Iterable[str]) -> dict:
    """
    Apaga uma lista de nomes do storage. Best-effort por item.

    Retorna:

        {
            'requested': 12,
            'deleted': 10,
            'failed': 2,
            'errors': [{'name': '...', 'error': '...'}, ...],
        }
    """
    from django.core.files.storage import default_storage

    names = list(names or [])
    deleted = 0
    failed = 0
    errors = []

    for name in names:
        try:
            default_storage.delete(name)
            deleted += 1
        except Exception as exc:
            failed += 1
            errors.append({'name': name, 'error': str(exc)})
            logger.exception(
                'Falha ao remover órfão: name=%s', name,
            )

    logger.info(
        'Limpeza de órfãos: requested=%d deleted=%d failed=%d',
        len(names), deleted, failed,
    )

    return {
        'requested': len(names),
        'deleted': deleted,
        'failed': failed,
        'errors': errors,
    }


# =========================================================================
# MANAGEMENT COMMAND HELPER
# =========================================================================

def cleanup_workspace(workspace, dry_run: bool = True) -> dict:
    """
    Combina detecção + limpeza.

    Se `dry_run=True` (padrão), só reporta os órfãos, sem apagar.

    O parâmetro `workspace` hoje é apenas informativo (aparece no
    log). A detecção é global porque a checagem de vivos também é.
    """
    orphans = find_orphan_images(workspace=workspace)

    if dry_run or not orphans:
        return {
            'dry_run': True,
            'orphans_found': len(orphans),
            'orphans': orphans,
            'deleted': 0,
            'failed': 0,
        }

    report = delete_orphan_images(orphans)
    report['dry_run'] = False
    report['orphans_found'] = len(orphans)
    return report

        name = (name or '').strip()
        if not name:
            raise ReferenceCategoryError('O nome da categoria não pode ser vazio.')
        if len(name) > 60:
            raise ReferenceCategoryError(
                'O nome da categoria pode ter no máximo 60 caracteres.'
            )

        base_slug = slugify(name) or 'categoria'
        slug = base_slug
        counter = 1
        while ReferenceCategory.objects.filter(
            workspace=workspace, slug=slug
        ).exists():
            counter += 1
            slug = f'{base_slug}-{counter}'

        max_pos = (
            ReferenceCategory.objects
            .filter(workspace=workspace)
            .order_by('-position')
            .values_list('position', flat=True)
            .first()
        ) or 0

        try:
            cat = ReferenceCategory.objects.create(
                workspace=workspace,
                name=name,
                slug=slug,
                color=(color or '').strip()[:20],
                is_system=False,
                position=max_pos + 1,
                created_by=actor,
            )
        except IntegrityError as exc:
            raise ReferenceCategoryNameConflictError(
                f'Já existe uma categoria chamada "{name}" neste workspace.'
            ) from exc

        return cat

    @staticmethod
    @transaction.atomic
    def rename(*, category, new_name: str = None, color: str = None, actor=None):
        if new_name is not None:
            new_name = new_name.strip()
            if not new_name:
                raise ReferenceCategoryError(
                    'O nome da categoria não pode ser vazio.'
                )
            if len(new_name) > 60:
                raise ReferenceCategoryError(
                    'O nome da categoria pode ter no máximo 60 caracteres.'
                )
            conflict = (
                ReferenceCategory.objects
                .filter(workspace=category.workspace, name__iexact=new_name)
                .exclude(pk=category.pk)
                .exists()
            )
            if conflict:
                raise ReferenceCategoryNameConflictError(
                    f'Já existe uma categoria chamada "{new_name}".'
                )
            category.name = new_name

        if color is not None:
            category.color = (color or '').strip()[:20]

        category.save(update_fields=['name', 'color', 'updated_at'])
        return category

    @staticmethod
    @transaction.atomic
    def delete(category):
        if category.is_system:
            raise ReferenceCategoryError(
                'Categorias do sistema não podem ser excluídas.'
            )
        category_id = category.pk
        category.delete()
        return {'deleted': True, 'id': str(category_id)}

    @staticmethod
    def ensure_defaults(workspace, actor=None):
        ReferenceCategory.ensure_defaults(workspace, actor=actor)

    @staticmethod
    def _resolve_categories(workspace, category_ids):
        """
        Dado uma lista de UUIDs de categoria, devolve uma lista de
        instâncias de ReferenceCategory do mesmo workspace.
        Ignora IDs inexistentes/fora do workspace.
        """
        if not category_ids:
            return []
        ids = [str(c) for c in category_ids if c]
        if not ids:
            return []
        return list(
            ReferenceCategory.objects.filter(
                workspace=workspace, id__in=ids,
            )

    @staticmethod

    def upload(
        *,
        workspace,
        uploaded_file,
        title: str,
        description: str = '',
        category_ids: Optional[List] = None,
        client=None,
        project_id=None,
        folder=None,
        created_by=None,
        source: str = Reference.SOURCE_UPLOAD,
        source_url: str = '',
        visible_to_client: bool = False,
    ) -> Reference:
        ReferenceService._validate_and_detect(uploaded_file)

        title = (title or '').strip()
        if not title:
            raise ReferenceInvalidImageError(
                'O título da referência é obrigatório.'
            )

        description = (description or '').strip()

        if client is not None:
            ReferenceService._validate_client(workspace, client)
        if folder is not None:
            ReferenceService._validate_folder(workspace, folder)
        if source not in dict(Reference.SOURCE_CHOICES):
            source = Reference.SOURCE_UPLOAD

        original_name = uploaded_file.name or ''
        extension = Reference.extract_extension(original_name)
        size = getattr(uploaded_file, 'size', 0) or 0

        reference = Reference(
            workspace=workspace,
            title=title,
            description=description,
            client=client,
            project_id=project_id,
            folder=folder,
            source=source,
            source_url=(source_url or '')[:1000],
            visible_to_client=bool(visible_to_client),
            extension=extension,
            size=size,
            created_by=created_by,
            updated_by=created_by,
        )

        try:
            reference.image.save(original_name, uploaded_file, save=False)
        except Exception as exc:
            raise ReferenceStorageError(
                'Falha ao salvar a imagem no storage.'
            ) from exc

        reference.save()

        cats = ReferenceService._resolve_categories(workspace, category_ids)
        if cats:
            reference.categories.set(cats)

        ReferenceHistoryService.log(
            reference=reference,
            action=ReferenceHistory.ACTION_CREATED,
            user=created_by,
            previous_value=None,
            new_value={
                'title': reference.title,
                'category_ids': [str(c.id) for c in cats],
                'client_id': str(reference.client_id) if reference.client_id else None,
                'project_id': str(reference.project_id) if reference.project_id else None,
                'folder_id': str(reference.folder_id) if reference.folder_id else None,
                'source': reference.source,
                'source_url': reference.source_url or None,
                'visible_to_client': reference.visible_to_client,
                'extension': reference.extension,
                'size': reference.size,
            },
        )
        return reference

    @staticmethod
    @transaction.atomic
    def edit(
        *,
        reference: Reference,
        title: Optional[str] = None,
        description: Optional[str] = None,
        category_ids: Optional[List] = None,
        actor=None,
    ) -> Reference:
        changed = []
        prev = {}
        new = {}

        if title is not None:
            new_title = title.strip()
            if not new_title:
                raise ReferenceInvalidImageError(
                    'O título da referência é obrigatório.'
                )
            if new_title != reference.title:
                prev['title'] = reference.title
                new['title'] = new_title
                reference.title = new_title
                changed.append('title')

        if description is not None:
            new_desc = description.strip()
            if new_desc != reference.description:
                prev['description'] = reference.description
                new['description'] = new_desc
                reference.description = new_desc
                changed.append('description')

        if changed:
            reference.updated_by = actor
            reference.save(update_fields=changed + ['updated_by', 'updated_at'])

        if 'title' in prev:
            ReferenceHistoryService.log(
                reference=reference,
                action=ReferenceHistory.ACTION_RENAMED,
                user=actor,
                previous_value={'title': prev['title']},
                new_value={'title': new['title']},
            )
        other_prev = {k: v for k, v in prev.items() if k != 'title'}
        other_new = {k: v for k, v in new.items() if k != 'title'}
        if other_prev:
            ReferenceHistoryService.log(
                reference=reference,
                action=ReferenceHistory.ACTION_EDITED,
                user=actor,
                previous_value=other_prev,
                new_value=other_new,
            )

        # Categorias: substitui o conjunto inteiro
        if category_ids is not None:
            new_cats = ReferenceService._resolve_categories(
                reference.workspace, category_ids,
            )
            old_ids = sorted(str(c.id) for c in reference.categories.all())
            new_ids = sorted(str(c.id) for c in new_cats)
            if old_ids != new_ids:
                reference.categories.set(new_cats)
                ReferenceHistoryService.log(
                    reference=reference,
                    action=ReferenceHistory.ACTION_EDITED,
                    user=actor,
                    previous_value={'category_ids': old_ids},
                    new_value={'category_ids': new_ids},
                )

        return reference

    @staticmethod
    def storage_usage(workspace) -> dict:
        from django.conf import settings
        from django.db.models import Sum

        total_bytes = (
            Reference.objects
            .filter(workspace=workspace)
            .aggregate(total=Sum('size'))
            .get('total') or 0
        )
        total_bytes = int(total_bytes)

        quota_bytes = int(
            getattr(settings, 'REFERENCES_STORAGE_QUOTA_BYTES', 5 * 1024 ** 3)
        )
        if quota_bytes <= 0:
            quota_bytes = 5 * 1024 ** 3

        percent = min(100.0, (total_bytes / quota_bytes) * 100.0) if quota_bytes else 0.0

        return {
            'used_bytes': total_bytes,
            'quota_bytes': quota_bytes,
            'percent': round(percent, 2),
