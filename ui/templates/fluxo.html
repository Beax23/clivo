        Sobre as versões

        Uma foto do modelo

        Toda vez que você publica um modelo, a Clivo tira uma foto da estrutura naquele momento (sessões e perguntas). Essa foto é uma versão.

        Nada se perde

        Versões antigas ficam guardadas para sempre. Mudar o modelo não apaga o que veio antes.

        Voltar no tempo

        Se quiser voltar para uma versão anterior, clique na versão e depois em Restaurar. A Clivo substitui a estrutura atual pela da versão escolhida. Você pode revisar antes de publicar de novo.

        Briefings antigos ficam intactos

        Briefings já enviados para clientes usam uma cópia própria da estrutura. Mexer no modelo não afeta esses briefings — mesmo se você voltar para uma versão antiga.

        Criar uma nova versão?

        Este modelo está publicado. Para fazer alterações, é preciso criar uma nova versão em rascunho. A versão atual continua intacta e em uso pelos briefings existentes.

        • A versão publicada atual continua ativa
        • Uma nova versão em rascunho será criada
        • Você poderá editar e publicar quando quiser
